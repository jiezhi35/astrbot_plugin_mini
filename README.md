# 迷你玩家查询

迷你世界玩家与地图查询，全部渲染为毛玻璃风格长图。

## 指令

```
/mini 1531249328            玩家资料长图
/map 45557796758440         地图ID → 单个地图详情（含封面大图）
/map 198379                 迷你号 → 该玩家全部作品卡片网格图
/maps 198379                作品下载量排行，无框线表格图
/down 45557796758440        下载该地图的地图包文件
```

`map`、`maps` 都支持**迷你号或地图ID**：12 位及以上按地图ID处理、否则按迷你号处理，该路径失败会自动尝试另一种。

## down（下载地图包）

**用途：** 把某张地图的**完整地图包**（约 10MB 的 ZIP）发到群里，可用于备份地图、离线查看地图文件、或把他人地图导入自己账号。地图包里包含地图存档、自定义模型、自定义 UI、自定义音效等资源。

```
/down 45557796758440
```

| 项目 | 说明 |
|---|---|
| 参数 | 地图ID，1–25 位数字 |
| 成功 | 直接把 `.zip` 文件发到群里，文件名形如 `地图名-地图ID.zip` |
| 下载失败 | 回退为发送下载链接 |
| 发送失败 | 回退为发送下载链接（QQ 对文件大小有限制，10MB 不一定发得出去） |
| 下载超过 5 秒 | 发送「⚠️：地图文件正在下载中 请等待！」 |

**怎么拿到地图ID：** 游戏里打开地图时，左下角显示的「迷你号ID」就是。注意 `/mini` 接口返回的作品列表里**不含**地图ID，无法从玩家数据反查——这是上游就不提供该字段。

**底层接口**（也可以直接调用）：

```
GET https://jiezhi.xyz/mini/download?wid=<地图ID>
```

返回 `application/zip`，响应头带文件名；同 IP 每分钟 20 次限流。

## 渲染

- 画布宽 1600px，高度自适应，JPEG 输出。
- 背景取 `https://api.yppp.net/pc.php` 随机图，20% 不透明度叠加。
- 面板为毛玻璃：背景高斯模糊 + 提亮回填 + 白色薄雾 + 高光描边。
- 字体为霞鹜文楷 Bright Medium。

| 指令 | 形态 |
|---|---|
| `/map <迷你号>` | 每作品一张卡片（上封面下详情），3 列成一张总图，最多 30 张 |
| `/maps` | 纯文字列排版，无任何格线，数值右对齐，下载量降序 |

## 回退策略

| 情况 | 行为 |
|---|---|
| 背景获取失败 | 复用上次成功的背景，再失败用纯色底 |
| 头像 / 封面获取失败 | 封面用「暂无封面」兜底图，不影响出图 |
| 渲染或发送失败 | 回退纯文本；`map`（卡片路径）/ `maps` 末尾附用法提示 |
| `down` 下载或发送失败 | 回退为发送下载链接 |
| 查询失败 | 明确报错，不伪造数据 |
| 渲染超过 5 秒 | 发送「⚠️：图片仍在渲染中 请等待！」 |
